# 好き顔ランキング

このリポジトリは、写真を選んで自分の「好き顔ランキング」を作る静的サイトです。

## 使い方

1. GitHub でこのリポジトリを開く
2. 「Settings」→「Pages」を開く
3. Source を「Deploy from a branch」に設定
4. Branch を `main`、Folder を `/ (root)` に設定
5. 保存後、数分待つ
6. 公開 URL でサイトを開く

例:
https://zz5ykgmk8w-cmd.github.io/sukigao-ranking/

## 注意

- 画像はリポジトリ直下の `IMG_XXXX.jpeg` をそのまま利用しています
- `sukigao_ranking.html` を開くとランキングサイトとして動作します
- GitHub Pages では静的ファイルとして公開されます
